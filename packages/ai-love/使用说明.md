# 爱ai 使用说明

爱ai 做三件事：**帮 QQ 会话记住事实、维护 AI 自己的角色卡与隐私记录，并在上下文快满时把旧聊天压成一张纯事实记忆卡。**
压缩记忆卡只写事实；角色卡和隐私记录是独立档案，不会混进记忆卡。

---

## 一、装好之后先看哪里

1. 打开 DSH，看左侧栏有没有「爱ai」图标；
2. 点开图标，面板顶部会显示「记忆卡 / 待确认 / 事实 / 压缩」的数字；
3. 数字下面的「刷新」可以手动刷新，面板本身每 15 秒自动刷新一次。

如果图标没出现：在 DSH 里退出（托盘右键 → 退出），重新打开。插件只在启动时加载。

---

## 二、面板每一块是干什么的

| 你看到的区块 | 它显示什么 | 你能做什么 |
|---|---|---|
| 概览 | 记忆卡数量、待确认、事实、压缩统计 | 看 |
| 逻辑痕迹 | 什么时候压过、成功还是失败、为什么 | 看 |
| 记忆卡 | 每个会话最近的压缩结果 | 看 |
| 拿不准的记忆 | AI 记不清、想问你的条目 | 在输入框回复，回传给 QQ 上的 AI 确认 |
| 记忆事实 | 已经确认的长期事实 | 看 |
| 角色卡 | AI 当前的角色卡、改卡申请与变更历史 | 编辑并提交改动；AI 表态后放行/拒绝 |
| 隐私记录 | AI 写的隐私记录与查看申请 | 审批查看；退役后按亡语/永恒秘密规则展示 |
| 压缩自检 | 这次压缩删什么、留什么，AI 是否同意 | 看 AI 表态和超时/强制记录 |
| 与「小肥鱼鲸鱼娘」自动联通 | 本插件开关、对方开关状态、互通目录、上次同步结果 | 打开/关闭自动联通；点「立即同步」手动跑一次；下面也能手动导出/导入 JSONL |
| 防火墙 | 核心记忆档案有没有被改动 | 重新基线、扫描、加固 |
| token 统计 | 注入文本大概占多少 token | 看；必要时放宽/收缩预算档位 |
| 备份 | 面板文档备份到哪个盘、上次同步时间 | 立即同步、打开文件夹、一键找回 |
| 上下文联通 | QQ 会话日志是否联接到非系统盘 | 看 |

面板里只有这些是写操作：回复拿不准、改卡/放行、隐私查看审批、自动联通开关/立即同步、互通导入/导出、备份同步/找回、token 档位、防火墙操作。其它都是只读。

## 三、压缩是怎么发生的

1. 聊天越来越长，接近模型上下文窗口的阈值；
2. 爱ai 把较早的一段历史压成记忆卡，留下最近一段原文；
3. 记忆卡只写事实：在聊什么、谁是谁、发生过什么、约定了什么、当前状态、关键词；
4. 记不清的地方标 `(?)`，同时写进「拿不准」，下一轮提醒 AI 找机会问你；
5. 你回复「拿不准」后，AI 会用 `compact_pending` 表示接受或不认同。

压缩失败不会动聊天记录：失败就保持原样，面板「逻辑痕迹」里能看到原因。

## 四、角色卡与隐私记录

### 角色卡

- 角色卡由 AI 从自己的言行里归纳（`character_summarize`），也可以由你在面板直接编辑；
- 你提交的改动默认是二级：先等 QQ 上的 AI 表态，它同意后再在面板放行；
- 如果 profile 显式开启 `allowLevel3`，面板可以三级直通，改动立即生效；
- 每次改动都会写进变更历史，备份里的「06-角色卡」能看到卡、言行、申请和历史。

### 隐私记录

- 隐私记录只能由 AI 自己写（`legacy_write`），面板只能读状态、不能改正文；
- 别的 AI 想读你的记录，要先发查看申请，由 AI 审批（`legacy_review`）；
- AI 退役后按最后一次申请结果处理：通过 = 亡语可读，未通过 = 永恒秘密不可读；
- 备份只在退役且可读时保留正文，其余只写状态。

## 五、跨插件互通怎么用

### 自动联通（默认开启）

1. 两个插件都装好、DSH 完整重启后，各自启动；
2. 两个面板的开关默认都开着，`~/.dsh/memory-bridge` 里会出现 `ai-love.jsonl`、`xiaofeiyu-whale.jsonl`、`link.json`；
3. 启动后各跑一次，之后每 60 秒自动同步一次；
4. 任何一边关掉开关，两边都会停止自动同步（面板会写清是谁关的）；
5. 「立即同步」不受开关限制，随时可以手动跑一次。

两个开关必须都开，自动联通才会进行；只想停一边就关那一边，另一边面板会显示「对方关着」。

### 从爱ai 导出给 Python 记忆系统

1. 面板 → 「与「小肥鱼鲸鱼娘」自动联通」→ 手动互通 → 点「导出记忆」；
2. 默认写到 `~/.dsh/ai-love/interop/ai-love-export.jsonl`，面板会显示条数和路径；
3. 把这个 JSONL 交给 Python 侧导入。

### 从 Python 记忆系统导入爱ai

1. 把 Python 导出的 JSONL 放到记忆目录或 `bridgeDir` 内；
2. 面板 → 「与「小肥鱼鲸鱼娘」自动联通」→ 手动互通 → 选择文件 → 点「导入记忆」；
3. 面板显示：摘要/事实/待确认/备注各新增多少、更新多少、跳过多少；
4. 同一个文件再导一次不会翻倍，只会更新。

### 会话归属（群聊/私聊）怎么对齐

在插件配置里写 `sessionScopes`，把 DSH 的会话 id 映射到 QQ 作用域：

```json
"sessionScopes": {
  "dsh-1": { "chat_type": "group", "group_id": "20002", "peer": "10001" },
  "dsh-2": { "chat_type": "private", "peer": "10001" }
}
```

Python 侧导入时传同一份映射。没登记的会话会各自隔离成独立私聊，不会串到真实会话。

## 六、备份

### 面板文档备份

- 默认在非系统盘建 `<盘>:\爱ai`，每 10 分钟把面板模块写成 Markdown；
- 「立即同步」马上写一次；「打开文件夹」直接打开备份目录；
- 「一键找回」用备份覆盖回档案；覆盖前会把当前档案另存到 `_restore-<时间>`，可以手动回退。

### 逐字节备份

- 把 `~/.dsh/sessions` 里的 QQ 会话日志和 `~/.dsh/ai-love` 档案实时镜像到非系统盘；
- 9MiB 的会话日志也按原始字节复制，不设大小上限；
- 面板「备份」区块能看到备份根目录和最近一次快照。

## 七、常见问题

**Q：压缩会不会把我喜欢的聊天弄丢？**
A：记忆卡只压「过场和重复」，事实、原话、约定会保留；拿不准的会留在档案里等确认。

**Q：面板能不能直接改记忆？**
A：不能。面板只读记忆和事实；确认/丢弃「拿不准」要在 QQ 里由 AI 操作，面板只负责把你的回复传回去。

**Q：角色卡会混进压缩记忆吗？**
A：不会。角色卡和隐私记录是独立档案；压缩记忆卡只写事实，协议校验会拒绝人设/语气/情绪小节。

**Q：导入后事实变多了/状态不对？**
A：导入按 `source + external_id` 去重；已确认、已拒绝的事实不会被迟到的旧记录改回。若看到异常，先在面板「防火墙」扫描，再检查互通文件里的 `status`。

**Q：QQ 会话日志在哪？**
A：`~/.dsh/sessions` 下名字带 `qq-bridge` 的会话组。逐字节备份会包含它们；只在 DSH 退出后再手动搬动。
