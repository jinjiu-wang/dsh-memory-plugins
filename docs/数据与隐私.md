# 数据与隐私

两个插件的原则一样：**记忆是本机的东西**。插件自己不往任何第三方服务器发数据，没有遥测，没有统计上报。

---

## 一、数据写在哪

### 爱ai

```text
<DSH_HOME>/ai-love/
├── summaries/<会话>.jsonl     压缩记忆卡（按会话隔离）
├── uncertain.jsonl            拿不准 / 待确认
├── facts.jsonl                长期事实
├── character/                 角色卡、言行记录、改卡申请、变更历史
├── legacy/                    隐私记录（按 aiId 隔离）
├── activity.jsonl             压缩留痕
├── compact-consent.json       压缩提案与表态
├── interop/                   互通 JSONL 与本地开关（auto.json）
├── guard/                     档案基线（SHA-256）与告警
└── firewall.log               运行时防火墙记账
```

面板备份目录（默认自动挑非系统盘，通常 `<盘>:\爱ai`）：

```text
爱ai/
├── 01-概览.md … 09-上下文联通.md     面板各区块的文字备份
├── 06-角色卡/  07-隐私记录/          独立目录
├── _raw/memory/                      导出前的原始档案快照
└── backup.json                       备份状态
```

### 小肥鱼鲸鱼娘

```text
<DSH_HOME>/xiaofeiyu-whale/
├── memory.db        SQLite：消息、摘要、事实、待确认、会话作用域
└── settings.json    本地面板开关
```

### 两个共用

```text
<DSH_HOME>/memory-bridge/
├── ai-love.jsonl
├── xiaofeiyu-whale.jsonl
└── link.json
```

`<DSH_HOME>` 默认是 `~/.dsh`（Windows：`C:\Users\<你>\.dsh`），可用 `--dsh-home` 或环境变量 `DSH_HOME` 改。

---

## 二、什么不会离开本机

- 记忆卡、事实、拿不准、角色卡、隐私记录、SQLite 数据库：全部落盘在本机，不上传。
- 互通 JSONL：只在本机两个插件之间流转，路径就是上面的 `memory-bridge/`。
- 备份：写到你指定的本地目录（默认非系统盘）。
- 插件自身不发遥测、不拉配置、不访问外网。爱ai 的运行时防火墙还会挡住插件代码自己的越界出站请求。

压缩记忆卡时用的是 DSH 自己的模型调用——那是 DSH 在跑，跟插件发包无关；插件只负责「压之前写什么、压完存什么」。

---

## 三、包里不含什么

发行包只装功能代码，**不含任何使用者的内容**。每个包里的 `PURE.md` 是这份说明的副本，组合包的 `verify-pure.mjs` 可以随时重跑检查：

- 没有人格提示词、agent preset（`qq-chat*.yml`、`agent.cordis.yml`）
- 没有角色卡正文与言行记录（`character/`、`card.md`、`behavior.jsonl`）
- 没有聊天记录、记忆库、事实、摘要、隐私记录（`*.jsonl`、`*.db`、`summaries/`、`legacy/`）
- 没有原使用者的本机路径、QQ 号、安装状态
- `cordis.patch.yml` 里的备份/联通/数据目录已清空，由安装器按你的环境重新写入

角色卡功能装完是**空的**：需要你自己的 AI 从言行里归纳，或你在面板里写。

## 四、几处要自己留意的

| 操作 | 影响 |
|---|---|
| 逐字节备份（`memoryBackup`） | 会把 QQ 会话日志和记忆档案**原样**复制到备份盘，包括历史数据。选一个你信得过的盘 |
| 上下文联通（`contextLinkDir`） | 用目录联接把会话日志挂到非系统盘，只读查看；搬迁时建议先退出 DSH |
| 隐私记录（`legacy/`） | 只由 AI 自己写；面板与别的 AI 只能按「亡语 / 永恒秘密」规则只读 |
| 角色卡改卡 | 默认二级：AI 表态后管理端放行；只有 profile 显式开 `allowLevel3` 才直通 |
| 运维防火墙记账 | `firewall.log` 只记操作类别与时间，不记正文 |

## 五、删数据 / 搬家

**只删某类记忆**：直接删 `<DSH_HOME>/ai-love/` 下对应文件/目录（先退出 DSH）。互通文件删了会自动重建。

**搬家**：把 `<DSH_HOME>/ai-love/`、`<DSH_HOME>/xiaofeiyu-whale/`、`<DSH_HOME>/memory-bridge/` 三个目录一起拷到新机器同一位置，装好插件即可。备份目录可以另外指定。

**彻底清掉**：

```powershell
node uninstall-all.mjs --purge-all     # 连记忆数据一起删
```

注意：`--purge-all` 会删数据目录，但共享互通目录在单边 `--purge` 时仍保留（另一边可能还在用）。确认两边都不用再清。

## 六、报 issue 前

别贴这几样：

- QQ 号、群号、聊天原文、记忆卡正文
- 角色卡、隐私记录
- 任何 token / cookie / 密钥
- 完整本机路径（可以用 `<DSH_HOME>` 代替）

可以贴：版本号、DSH 版本、面板报错原文、`link.json` 里的两个布尔值、安装器最后几行输出。
