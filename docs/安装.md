# 安装

两个插件可以一起装，也可以分开装。安装器是幂等的：重跑不会搞坏已有安装，数据都留着。

---

## 一、先确认

| 项 | 要求 | 不满足会怎样 |
|---|---|---|
| DSH | 已安装且能正常启动 | 安装器找不到 profile，直接退出 |
| Node.js | ≥ 22 | 语法与依赖检查失败 |
| Python | ≥ 3.10，带 `sqlite3` | 只有小肥鱼鲸鱼娘受影响；爱ai 照常 |
| qq-bridge | 可选 | 没有时爱ai 只能装插件本体（`--no-preset`），不接管 QQ 压缩 |

Windows PowerShell 下直接跑 `node` 即可；DSH 自带的 Node 也能用。

---

## 二、拿到代码

两种方式，选一种：

**A. 仓库源码**（推荐，方便以后更新）

仓库页面点 **Code → Download ZIP**，或复制仓库地址后：

```powershell
git clone https://github.com/jinjiu-wang/dsh-memory-plugins.git
cd dsh-memory-plugins
```

**B. Release 压缩包**

在 Releases 页面下载，任选一个：

| 文件 | 里面是什么 |
|---|---|
| `ai-love-xiaofeiyu-whale-combo-1.0.0.zip` | 组合包：两个插件 + 一键安装/卸载/校验脚本 |
| `ai-love-0.20.4-pure.zip` | 只有爱ai |
| `xiaofeiyu-whale-0.2.0-pure.zip` | 只有小肥鱼鲸鱼娘 |

解压后进目录，后面的命令一样。

---

## 三、组合安装（两个一起）

```powershell
node install-all.mjs
```

脚本做四件事：

1. 找 DSH profile（默认 `desktop`，其次 `web`）；
2. 找 qq-bridge（参数、环境变量、或从 `qq-agent-presets` 反推）；找不到就只装插件本体；
3. 找 Python（`--python` → `XIAOFEIYU_PYTHON` → DSH 运行时目录 → PATH）；
4. 依次调用两个包自己的安装器，任一失败会汇总报出来。

常用参数：

```powershell
node install-all.mjs --dry-run                 # 只看计划，不写盘
node install-all.mjs --profile desktop         # 指定 profile
node install-all.mjs --dsh-home "C:\tmp\dsh"   # 沙盒 / 自定义 DSH_HOME
node install-all.mjs --repo "D:\qq-bridge"     # 指定 qq-bridge
node install-all.mjs --no-preset               # 只装插件本体，不改 QQ preset
node install-all.mjs --python "C:\...\python.exe"
node install-all.mjs --skip-ai-love            # 只装小肥鱼鲸鱼娘
node install-all.mjs --skip-whale              # 只装爱ai
```

**装完必须完整退出 DSH**（托盘图标右键 → 退出，不是关窗口）再打开。插件只在启动时加载。

## 四、单独安装

两个包在 `packages/` 下都是完整的独立包，可以只装一个。

### 爱ai

```powershell
cd packages\ai-love
node install.mjs --repo "D:\qq-bridge"     # 有 qq-bridge：接管 QQ 会话压缩
node install.mjs --no-preset               # 没有：只装面板与记忆本体
```

| 参数 | 作用 |
|---|---|
| `--repo <dir>` | qq-bridge 目录（含 `src/bridge.js`、`config.json`、`dsh/agent-presets`） |
| `--no-preset` | 不碰 QQ preset，只装插件本体 |
| `--profile <name\|path>` | 指定 DSH profile |
| `--dsh-home <dir>` | 指定 DSH_HOME（沙盒用） |
| `--backup-dir <dir>` | 面板备份目录；默认自动挑非系统盘 |
| `--memory-backup-dir <dir>` | 逐字节备份根（会话日志 + 记忆档案） |
| `--dry-run` | 只看计划 |

安装器会：复制到 `<DSH_HOME>/plugins/ai-love` → 在 profile 里注册 bundle → 给 QQ preset 换上 ai-love 压缩后端（有 `--repo` 时）→ 把 14 个模型侧工具加进 QQ 工具白名单 → 语法与 patch 校验 → 写安装状态供卸载回滚。

> 没有 qq-bridge 时，面板、记忆、备份、互通都能用；之后找到 qq-bridge，用 `--repo` 重装一次即可补上 QQ preset。
>
> 如果 qq-bridge 已接入安全屋门闸，安装器会识别并说明；没接入时会提示，但**不影响聊天**。

### 小肥鱼鲸鱼娘

```powershell
cd packages\xiaofeiyu-whale
node install.mjs
```

| 参数 | 作用 |
|---|---|
| `--python <exe>` | 指定 Python 解释器 |
| `--data-dir <dir>` | 数据库目录（默认 `<DSH_HOME>/xiaofeiyu-whale`） |
| `--bridge-dir <dir>` | 互通目录（默认 `<DSH_HOME>/memory-bridge`） |
| `--profile <name\|path>` | 指定 DSH profile |
| `--dsh-home <dir>` | 指定 DSH_HOME |
| `--dry-run` | 只看计划 |

安装器会：复制到 `<DSH_HOME>/plugins/xiaofeiyu-whale` → 以 `file:` 依赖装进 profile 并注册 bundle → 把目录与开关默认值写进 `cordis.patch.yml` → 校验 JS / Python 语法与运行时。

> 鲸鱼娘需要 Python，但不需要 qq-bridge。

---

## 五、装完核对

1. 完整退出 DSH 再打开；
2. 左侧栏出现「爱ai」和/或「小肥鱼鲸鱼娘」图标；
3. 点开面板，顶部数字/状态能刷新出来；
4. 两个都装了的话：两个面板的「自动联通」都显示开着，`<DSH_HOME>/memory-bridge/` 里出现三份文件。

命令行校验：

```powershell
node packages\ai-love\verify.mjs
node packages\xiaofeiyu-whale\verify.mjs
```

---

## 六、升级

重跑安装器即可，链路上是幂等的：

```powershell
# 组合
node install-all.mjs

# 单独
cd packages\ai-love
node install.mjs --repo "D:\qq-bridge"
```

记忆、角色卡、隐私记录、数据库都在 `<DSH_HOME>` 下的数据目录里，升级不会清。装完同样要完整退出 DSH 再开。

---

## 七、卸载

```powershell
node uninstall-all.mjs                 # 默认保留记忆数据
node uninstall-all.mjs --dry-run       # 只看计划
node uninstall-all.mjs --purge-all     # 连记忆库一起删（谨慎）
```

单独卸载：

```powershell
cd packages\ai-love
node uninstall.mjs
```

```powershell
cd packages\xiaofeiyu-whale
node uninstall.mjs            # 保留数据库
node uninstall.mjs --purge    # 删自己的数据目录
```

共享互通目录 `<DSH_HOME>/memory-bridge` 即使 `--purge` 也会保留——另一个插件可能还在用。

## 八、数据写到哪

| 插件 | 默认位置 | 内容 |
|---|---|---|
| 爱ai | `<DSH_HOME>/ai-love/` | 摘要、事实、拿不准、角色卡、隐私记录、防火墙基线、互通 JSONL |
| 小肥鱼鲸鱼娘 | `<DSH_HOME>/xiaofeiyu-whale/` | `memory.db`、`settings.json` |
| 两个共用 | `<DSH_HOME>/memory-bridge/` | 两份 JSONL + `link.json` |
| 爱ai 备份 | 自动挑非系统盘，默认 `<盘>:\爱ai` | 面板文字备份、`_raw/` 原始档案快照 |

详见 [数据与隐私.md](数据与隐私.md)。
