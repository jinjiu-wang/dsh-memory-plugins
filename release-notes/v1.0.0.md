# 爱ai 0.20.4 + 小肥鱼鲸鱼娘 0.2.0 · 首次公开

两个给 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) 用的记忆插件，第一次一起发。可以各装各的，也可以一起装——一起装时，两边通过同一个目录自动交换记忆。

**不含任何 AI 人设数据**：没有角色卡正文、没有 agent preset、没有聊天记录或记忆库、没有原使用者的本机路径。所有数据留在本机。

---

## 爱ai 0.20.4

把 QQ 会话的上下文压小，同时不丢事实。

- **自动压缩**：接管 QQ 会话的压缩后端，到阈值触发；失败不写表层变更。
- **纯事实记忆卡**：话题、人物关系、时间线、约定、当前状态、关键词；拒绝人设/语气/情绪小节。
- **拿不准**：记不清的事进档案，下一轮提醒 AI 问用户；面板回复，结果带回 QQ。
- **长期事实**：按会话隔离，确认过的注入系统提示。
- **角色卡**：从言行归纳，二级改动要 AI 表态 + 管理端放行。
- **隐私记录**：只由 AI 自己写，继承时按「亡语 / 永恒秘密」规则读取。
- **档案基线**：核心记忆档案 SHA-256 基线，发现改动、缺失、新增。
- **面板备份 + 逐字节备份**：面板模块写成文字文档备份到非系统盘，一键找回；会话日志与记忆档案可逐字节镜像。
- **压缩自检**：提案式压缩，AI 同意才压，拒绝有冷却，超时可兜底。
- **运行时防火墙（新增）**：出站网络、监听端口、越界写盘、危险子进程四层拦截，记账到 `<memoryDir>/firewall.log`。
- **安全屋（新增，可选）**：按消息压力给自己留一块不被打扰的区域；要让 QQ 唤醒真的停下来，需在 qq-bridge 上打一处补丁。
- **自进化沙盒（新增，默认不启用）**：闭环调度 + 注册表 + 哈希链日志，只写 `<memoryDir>/.evolve/`。

面板 13 个区块，模型侧 14 个工具。

## 小肥鱼鲸鱼娘 0.2.0

给记忆一个能查的库。

- Host 拉起本机 Python 记忆服务（stdio，不监听端口），SQLite 存消息、摘要、事实、待确认、会话作用域。
- 面板：记忆概览、自动联通、待确认、最近事实、最近摘要、FTS 检索原话。
- **新增「待确认」记忆**：与爱ai 的拿不准双向映射（独立 `uncertain` 表 ↔ `category='待确认'`），状态 open / confirmed / dropped 一一对应。
- **新增协议适配层**：两种记忆模型的字段对得上，普通事实不会被误当成待确认。

## 联动

```text
<DSH_HOME>/memory-bridge/
├── ai-love.jsonl            爱ai → 小肥鱼鲸鱼娘
├── xiaofeiyu-whale.jsonl    小肥鱼鲸鱼娘 → 爱ai
└── link.json                两边共享的总开关
```

- 启动后各跑一次，之后每 60 秒一次；文件没变就跳过。
- 三个开关都为开才自动同步（两个面板开关 + `link.json` 里两个值）；任一边关掉即停。
- 只交换摘要、事实、待确认、备注；人设、角色、语气、情绪不进互通文件。
- 详见仓库里的 `docs/联动用法.md`。

## 安装

解压后进目录：

```powershell
node install-all.mjs      # 组合包
node install.mjs          # 独立包
```

装完**完整退出 DSH**（托盘退出，不是关窗口）再打开。

要求：DSH 已安装；Node.js ≥ 22；小肥鱼鲸鱼娘需要 Python ≥ 3.10（带 `sqlite3`）；qq-bridge 可选（只有爱ai 接管 QQ 压缩时需要）。

## 已知限制

- 爱ai 只管 QQ 会话的压缩，不接管 web GUI 的全局压缩。
- 安全屋要挡住 QQ 唤醒，需要手动给 qq-bridge 打补丁；没打补丁时聊天不受影响，只是不挡。
- 自进化沙盒是原型，默认不启用。
- 主要开发与测试在 Windows 完成；macOS / Linux 未逐项验证。
- 两个插件都不提供人设。你的 AI 是什么性格，由你自己的 agent preset / 人格卡决定。
